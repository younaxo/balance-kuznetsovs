# Фото команды

Положите сюда файлы фото специалистов (jpg/png), затем впишите точное
имя файла в поле «Файл фото» карточки в /admin/team — фото появится на
сайте автоматически. Пока файла нет, на сайте показывается плейсхолдер
с инициалами вместо фото (никакие фото не подставляются "по памяти" —
см. DECISIONS.md).
